## ✨ Features & Main Sections

- **Hero & Profile Showcase:** Highlights role, summary metrics, quick actions, and downloadable resume.
- **About:** Overview of background, engineering focus, and core philosophy.
- **Experience:** Timeline of professional engineering roles, leadership accomplishments, and technical impact.
- **Projects:** Interactive cards detailing architecture, tech stacks, live links, and source repositories.
- **Skills:** Categorized matrix covering Programming Languages, Frontend, Backend & Systems, AI / GenAI, and DevOps & Cloud.
- **Resume Generator:** Built-in PDF resume generation for instant offline download.
- **Contact:** Interactive contact form with dynamic project type and budget selector, pre-filling a direct mailto workflow.
- **Fully Responsive & Theme-Ready:** Tailored for seamless viewing across mobile, tablet, and desktop viewports with dark mode support.

## 💻 Getting Started

Follow these instructions to set up and run the portfolio locally on your machine.

### Prerequisites

- **Node.js** (v18 or higher recommended)
- **npm**, **pnpm**, or **yarn**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ArfinAhmad217/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```text
   http://localhost:3000
   ```

---

## 🏗️ Build for Production

To create an optimized production build:

```bash
npm run build
```

The output will be generated inside the `dist/` directory, ready to be deployed to static hosting platforms (such as Vercel, Netlify, Cloudflare Pages, or Google Cloud Run).

To preview the production build locally:

```bash
npm run preview
```
